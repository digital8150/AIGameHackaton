# 요청: 좌상단 HUD — 감각 메달리온 2종 + 초상 2종

게임 『Dusk Princess and Twilight Prince』의 화면 좌상단 UI 이미지를 만들어 주세요.
이미지 생성 프롬프트를 써 주셔도 되고, 이미지를 직접 만들어 주셔도 됩니다.

## 1. 이 UI가 하는 일
- 지금 조작 중인 캐릭터(= 지금 세상을 느끼는 감각)를 보여 줍니다.
- 큰 메달리온은 지금 조작 중인 캐릭터, 작은 메달리온은 함께 다니는 다른 캐릭터입니다.
- 전환 키를 누르면 둘이 **자리를 바꿉니다**. 큰 쪽이 작아지고 작은 쪽이 커집니다.
  - 공주 조작 중: 큰 **금빛 해 메달리온**에 공주 초상, 작은 **은빛 달 메달리온**에 왕자 초상
  - 왕자 조작 중: 큰 **은빛 달 메달리온**에 왕자 초상, 작은 **금빛 해 메달리온**에 공주 초상
- 그래서 **고리와 초상은 따로 만든 이미지**여야 하고, 같은 고리를 크게도 작게도 씁니다.
- 글자는 넣지 않습니다. 이름은 게임이 따로 표시합니다.

## 3. 만들 것 (4장)

### A. 금빛 해 메달리온 고리 — `medallion_light.png`
- 공주(빛의 감각)의 고리. 앤티크 금, 해·햇살 모티프.
- 목업처럼 **얇고 깔끔한 금 고리 + 상하좌우 4곳의 작은 마름모 장식** 정도의 절제된 디자인.
  작게(지름 약 60px) 줄여도 형태가 읽혀야 합니다.

### B. 은빛 달 메달리온 고리 — `medallion_dark.png`
- 왕자(소리의 감각)의 고리. 낡은 은, 초승달·소리 물결(동심원) 모티프.
- A와 **형태·두께·장식 위치가 짝을 이루는** 디자인 (같은 틀, 재질과 문양만 다름).

**A·B 공통 규격 (중요)**
- 512 × 512 px, PNG, **투명 배경**.
- 고리 바깥 지름은 캔버스를 거의 꽉 채움 (여백 2~4%).
- **가운데는 완전히 투명한 원형 구멍**, 지름 = 캔버스의 **56%** (약 287 px), 정중앙.
  - 초상이 이 구멍 뒤에 깔립니다. 구멍이 A·B에서 같아야 서로 바꿔 끼울 수 있습니다.
- 그림자·광채는 고리 바깥 2~4% 안쪽까지만 (잘리지 않게).

### C. 공주 초상 — `portrait_princess.png`
### D. 왕자 초상 — `portrait_prince.png`
- 512 × 512 px, PNG. 게임이 **원형으로 잘라** 고리 구멍 뒤에 놓습니다.
  - 안전 영역: 중심 지름 90% 원 안에 얼굴과 머리가 다 들어오게.
  - 배경은 투명 또는 어두운 보랏빛 단색(#3A2C42 근처). 원 밖은 잘려도 됩니다.
- 구도: 얼굴과 어깨까지(bust), 정면에서 살짝 3/4. 공주는 오른쪽, 왕자는 왼쪽을 보면 마주 보는 느낌이 됩니다.
- 디자인은 첨부한 치비 원본과 **같은 인물**로 맞춤 (머리색, 뿔, 눈가 붕대, 옷깃, 망토 색).
  - 공주: 백금빛 단발과 일자 앞머리, 작은 검은 뿔 2개, 보라·청록 눈, 송곳니 미소, 검은 레이스 목깃, 남보라 망토(안감 노을 금색)
  - 왕자: 옅은 금발 덥수룩한 단발, 앞머리 밑 흰 눈가 붕대, 상아색 레이스 목깃과 흰 망토, 금 장식
- 화풍: 목업과 같은 **수채화·색연필 그림책 톤**, 부드러운 얼굴 셰이딩.

## 4. 스타일 공통
- 동화책 삽화 질감(종이 결, 가는 세피아 선), 따뜻한 황혼 팔레트.
- 피할 것: 글자, 로고, 워터마크, 실존 게임 캐릭터와 비슷한 디자인, 과한 광택(3D 렌더 느낌).

- 고리를 A·B 외에 더 만든다면(예: 조작 중이 아닌 쪽용 흐린 버전) 필요 없습니다. 흐리게 하는 건 게임에서 처리합니다.
