# InGame 코어 씬 — 결정 사항 (닫힘)

기획서: *Dusk Princess and Twilight Prince — 해커톤 기획서* (Claude Docs, 2026-11-05)
이 문서는 기획서에서 열려 있던 항목을 구현을 위해 **확정**한 기록이다. 바꾸려면 여기부터 고친다.

## 1. 범위
| 항목 | 결정 |
|---|---|
| 씬 | 서장 + 기획서 스테이지 1~3, 빌드 순서대로 이어진다 (아래 1-1) |
| 포함 | 전환 + 두 렌더링, 버튼 조작, 반향(버튼 + 마이크 음량), 숨은 장치 + 빛 신호 퍼즐, 가짜 벽, 박자 빛 발판, 빛의 글자 제단, 체크포인트/낙사, 접근성 디렉터(Jev → 규칙 폴백), Whisper 음성 명령(로컬) |
| 제외 | 온라인 랭킹/세이브, 스테이지 선택 화면(챕터는 클리어 카드 → Space로 이어짐) |

## 1-1. 챕터
| 빌드 | 씬 | 타이틀 | 내용 | 디렉터 구역 |
|---|---|---|---|---|
| 0 | `Ch0_Prologue` | 서장 · 첫 황혼 | 플레이어용 단계별 튜토리얼 5단계: 걷기/점프 → 감각 전환(Tab) → 메아리(R)로 보이지 않는 돌 건너기 → 금빛 등불에 레버(E) → 문. 단계가 끝나야 빛의 장막이 걷힌다. 디버그 키(F1/F2)·디렉터는 가르치지 않는다 | 없음 |
| 1 | `Ch1_PrinceInDark` | 제1장 · 어둠 속의 왕자 | 왕자로 시작. 메아리 돌 구덩이 2곳(두 번째는 물방울 소리 랜드마크), 막다른 벽처럼 보이는 **가짜 벽**(빛으론 벽, 메아리엔 속이 빈 따뜻한 색), 메아리 돌 계단 → 절벽 위 문 | drip·wall = sound |
| 2 | `Ch2_PrincessInLight` | 제2장 · 빛 속의 공주 | 공주로 시작. 박자에 맞춰 켜지는 **빛 발판**(공주에게만 보임, 켜진 동안만 밟힘, 꺼지기 전 깜빡임) 협곡, **빛의 글자 제단**: 공주에게만 보이는 "해질녘"을 말하거나(V) 선택지(E)로 부르면 글자가 다리가 된다. 오답은 무너짐. 빛 발판 계단 → 문 | planks·climb = timing, altar = visual |
| 3 | `InGame` | 제3장 · 황혼 | 기존 수직 슬라이스 (울림돌 협곡 + 황혼의 문). 마지막 장 → "— 끝 —" | canyon = sound, gate = timing |

- 챕터 공통 오브젝트(Systems/카메라/하늘/HUD/Voice)는 `InGame`을 복사해 시작하고, 레벨 내용만 eval로 다시 짓는다. **타일을 다시 칠하면 TilemapCollider2D를 껐다 켜서 Composite를 재생성**해야 한다 (복사본은 원본 충돌 형태를 그대로 들고 있다).
- 보이지 않는 돌(`M_EchoStone`): 빛 감각 알파 0 + 드문 픽셀 반짝임만, 어둠 감각에서는 메아리가 닿을 때만 보인다.
- **메아리 크기 (기획 수치 기준)**: 왕자 메아리는 3단계 — 소(R 0.25초 미만 / 작은 소리) 반지름 5m, 중(0.25~0.7초 / 보통) 10m, 대(0.7초 이상, 즉시 발사 / 큰 소리) 15m. 종은 고정 6m. 종·스위치는 반지름의 85%까지 듣는다(스위치는 머리 반경 0.4m 추가 → 소 4.65/중 8.9/대 13.15, 종 5.1/5.5). 수치는 `EchoCaller`(m 단위)·`EchoResonator.ringRadius` 인스펙터에 있다. 마이크 음량은 0.2초 피크로 크기를 고른다.
- **종 연쇄**: 종은 다른 종 소리에도 울린다(`answersBells`). 스위치는 왕자의 부름(`answersCalls`)과 종소리(`answersBells`)를 각각 들을지 고른다 — 5단계 바닥 스위치는 종소리만.
- **함정 스위치**: `SwitchGate.forbidden`. 필요한 스위치가 다 켜져도 `settleTime`(0.7초) 동안 기다려, 같은 메아리가 더 멀리 있는 함정에 닿으면 전부 꺼진다.
- **구간 리셋**: `StageSection`(x 범위) — 그 구간에 서면 시작점이 리스폰 지점이 되고, 떨어지면 구간 안의 `IResettable`(스위치·게이트·빈칸 다리·계단·종)이 처음 상태로. 열린 문·완성된 다리는 그대로 둔다.
- **반대로 계단**: `WordStair` — 말한 단어의 글자가 계단 칸이 되어 차례로 켜졌다 꺼진다. `topFirst`면 위에서부터 켜져 오를 수 없고, "반대로"가 순서를 뒤집는다.
- **스테이지 전환 = 그림책 넘김**: `PageTurn`(Prefabs/UI/PageTurn, 셰이더 `UI/PageTurn`) — 클리어 카드가 뜬 마지막 화면을 종이 한 장으로 찍어 덮고, 다음 스테이지를 그 뒤에서 로드한 뒤 넘기기 전에 해진 그림책 한 장으로 바랜다(세피아 잉크·얼룩·탄 가장자리·가운데 제본선, `M_PageTurn`의 Worn storybook 값, `PageTurn.ageTime`), 그다음 모서리부터 말려 넘어간다(뒷면은 낡은 종이결 + 비치는 그림). 소리 `Audio/page_turn.wav`(로컬 생성). 프리팹이 비어 있으면 기존 암전(`SceneTransition`). 타이틀 → 1단계는 암전 그대로.
- **프롤로그 『황혼의 그림책』**: 타이틀 → `Prologue_Storybook` → 1단계. 12장(전쟁 → 귀를 잃고 추방된 공주 → 저주받은 숲 앞에 선 공주(뒷모습) → 암습으로 눈을 잃은 왕자 → 탑 → 탑 붕괴 → 어두운 숲 → 만남 → 공주는 왕자의 말을 듣지 못한 채 해맑은 얼굴에 → 샘 이야기는 해설이 전함 → 따라나섬). 공주는 못 듣는다: 왕자의 대사를 공주 시점 문구로 쓰지 않는다. 스페이스/E/클릭/→ 넘김, Esc 건너뛰기.
- **말 무게 발판 (2단계 '떠오르는 말')**: 옛 '호수 글자' 방을 교체. 판정은 로컬 Kanana 1.5 2.1B(Apache-2.0, llama.cpp Vulkan, 단어당 약 80ms, 테스트 54단어 중 51개 정답)만 쓰고 Jev는 쓰지 않는다. 답은 '가벼움/보통/무거움' 3개로 강제(4번째 '모름'을 넣으면 정확도 94%→83%), 인사말·감탄사는 사전의 notThings로 거른다. 미리 새긴 '깃털'(떠 있음)·'바위'(가라앉음)로 규칙을 보여 준다. 대체 입력: 깃털 / 의자 / 바위.
- **엔딩**: `GameFlow.twilightEnding` — 클리어 시 화면을 두 감각의 중간(0.5)으로 섞고 클리어 카드가 타이틀 카드가 된다.

## 2. 슬라이스 구성 (왼→오)
1. **시작 언덕** — 이동/점프/전환 학습.
2. **울림돌 협곡** (단서=소리, 행동=점프): 구덩이 위 발판은 항상 존재하지만 빛(공주)으로는 거의 투명한 유리. 왕자의 반향이 닿을 때만 윤곽이 드러난다. 떨어지면 체크포인트로.
3. **황혼의 문** (기획서 핵심 퍼즐): 벽 너머 톱니 장치는 왕자 모드에서만 들리고(소리+반향 파동) 레버 위치가 드러난다. 레버를 당길 타이밍은 공주 모드에서만 보이는 신호등이 금색일 때. 틀리면 장치가 걸려 1.5초 잠김.
4. **재회의 등불** — 골. 클리어 연출.

## 4. 캐릭터
- 두 사람은 항상 함께. 조작 중인 쪽이 리더, 다른 쪽은 리더의 0.3초 전 궤적을 따라간다(자율 반응 없음 — 기획서 "의도적으로 빠진 것"과 일치).
- 전환은 위치가 아닌 **감각 렌즈**: 조작 권한과 렌더 모드가 함께 바뀐다.
- 반향은 왕자 전용. 공주 모드에서 R은 "들리지 않음" 피드백(화면 진동선만).

## 5. 비주얼 (임시 아님)
- **공통 지오메트리, 렌더 패스만 다름**: 모든 월드 스프라이트가 `DuskTwilight/SenseSprite` 하나를 쓴다. 전역 셰이더 변수로 모드를 결정.
- **전환 연출**: 조작 캐릭터 위치에서 파면이 1초 동안 화면을 덮으며 세계가 뒤집힌다. 경계는 fbm으로 찢긴 종이처럼 일렁이고(`edgeTear`), 두꺼운 금빛 테두리와 불씨가 따라간다(`rimWidth`). 경계 뒤 어둠 쪽 띠(`scratchBand`)는 세계 전체가 흰 스크래치보드 선으로 드러난다. 순간 슬로모션(`hitStopScale/Time`)과 카메라 줌 펄스(`zoomPunch`). 값은 SenseController 인스펙터.
- **공주 모드(빛)**: 황혼 금색 그레이딩, 위쪽 림 라이트, 하단 장밋빛 그림자, 해·구름·안개가 흐르는 하늘(`DuskTwilight/Sky`). 소리는 `DuskTwilight/SoundGlyph` 진동선으로 보인다.
- **왕자 모드(어둠)**: 남색-검정. 텍스처의 어두운 외곽선을 흰 선으로 반전해 "윤곽만" 남기고, 반향 파면이 지나간 곳만 잠깐 드러난다. 소리 나는 장치는 주기적으로 스스로 파동을 낸다.
- 후처리: Bloom(임계 0.95) + Vignette 0.42 (URP Volume).
- **조명 (공주 감각 전용)**: SenseSprite가 URP 2D Light 텍스처를 받는다(`_LightReceive`, 원경·중경은 0.9). `Chapter/Lighting`(전역 앰비언트 0.3, 보랏빛) + `Chapter/MainCamera`의 Focus Light(플레이 영역만 밝게) + 캐릭터 Glow + 체크포인트·재회의 문 Lamp Light + `Environment/LightShaft`(가산, 볼류메트릭 빛줄기). 가장자리는 어둡고 플레이 띠만 밝게. 왕자 감각은 조명과 무관(반향만).
- **2.5D 레이어 (B안: 일러스트)**: 원경(하늘·언덕, factor 0.92) → 중경(숲 줄·고목·아치·절벽, 0.15~0.6, 땅 뒤) → 플레이 층(0) → 전경(음수 factor, 캐릭터 앞, sortingOrder 40+). `Parallax` + `Prefabs/Environment/Env_*`. 화면 위/아래 가장자리에 붙는 전경(덩굴·풀 띠·근접 나무)은 yFactor 0.85로 카메라 높이를 따라가 점프 시 윗/아랫변이 드러나지 않게 한다.
- 전경의 바람 흔들림·깊이 흐림·실루엣 음영은 그림이 아니라 `SenseSprite`의 `_WindAmp`/`_Blur`/`_Shade`로 준다 (그림은 선명한 정지 한 장).
- 일러스트 해상도 유지를 위해 Pixel Perfect Camera는 끈다 (Orthographic size 7.5 유지).
- **지형**: 타일맵은 충돌·레벨 구조 담당으로 유지하고 그림만 교체한다. 흙 단면은 `M_Env_GroundFill`(SenseSprite `_WorldTex`/`_WorldTile` — 월드 좌표로 이음매 없이 반복), 윗면 풀·이끼 띠는 `GroundLip` 컴포넌트가 타일의 노출된 윗면을 따라 자동 배치(씬에 저장되지 않고 타일 데이터에서 재생성). Kenney 장식 타일맵(Decoration)은 렌더러를 끈다. `GroundLip`은 윗면(풀), 옆면(바위 테두리, 왼쪽은 좌우 반전), 천장 아랫면(늘어진 뿌리)을 모두 처리하고, 레벨 바깥을 향한 면은 건너뛴다. 울림돌(Echo Stones)도 `_WorldTex`로 수정 단면 텍스처.
- **왕자 감각의 윤곽**: 일러스트는 해칭으로 전체가 어두워 Kenney용 윤곽 규칙(밝기 0.5 미만)이면 화면 전체가 빛난다. 머티리얼별 `_InkThreshold`로 조절 — 일러스트 0.16, 울림돌 0.35, Kenney 0.5. 원경·중경은 `_DarkAlpha` 0.3, 전경 0.55로 플레이 층을 우선 드러낸다.
