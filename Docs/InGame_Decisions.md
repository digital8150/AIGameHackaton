# InGame 코어 씬 — 결정 사항 (닫힘)

기획서: *Dusk Princess and Twilight Prince — 해커톤 기획서* (Claude Docs, 2026-11-05)
이 문서는 기획서에서 열려 있던 항목을 구현을 위해 **확정**한 기록이다. 바꾸려면 여기부터 고친다.

## 1. 범위
| 항목 | 결정 |
|---|---|
| 씬 | `Assets/Scenes/InGame.unity` 하나. 기획서 "스테이지 3. 황혼"의 수직 슬라이스 |
| 포함 | 전환 + 두 렌더링(시그니처 연출), 버튼 조작, 반향(버튼 + 마이크 음량), 숨은 장치 + 빛 신호 퍼즐, 체크포인트/낙사, 규칙 기반 접근성 디렉터 + 디버그 오버레이 |
| 제외 | Whisper(빛의 글자), Jev 실 API, 음성 명령. 디렉터는 `IDirectorBrain` 인터페이스 뒤에 규칙 기반 폴백으로 구현 → Jev는 나중에 같은 인터페이스로 교체 |

## 2. 슬라이스 구성 (왼→오)
1. **시작 언덕** — 이동/점프/전환 학습.
2. **울림돌 협곡** (단서=소리, 행동=점프): 구덩이 위 발판은 항상 존재하지만 빛(공주)으로는 거의 투명한 유리. 왕자의 반향이 닿을 때만 윤곽이 드러난다. 떨어지면 체크포인트로.
3. **황혼의 문** (기획서 핵심 퍼즐): 벽 너머 톱니 장치는 왕자 모드에서만 들리고(소리+반향 파동) 레버 위치가 드러난다. 레버를 당길 타이밍은 공주 모드에서만 보이는 신호등이 금색일 때. 틀리면 장치가 걸려 1.5초 잠김.
4. **재회의 등불** — 골. 클리어 연출.

## 3. 조작 (Input System, 코드에서 액션 생성)
| 동작 | 키보드 | 게임패드 |
|---|---|---|
| 이동 | A/D, ←/→ | 왼쪽 스틱, D-pad |
| 점프 | Space, W, ↑ | South(A) |
| 전환 | Tab, Q | North(Y) |
| 반향 | R | West(X) |
| 마이크 반향(푸시투톡) | V 누르는 동안 | LB |
| 상호작용 | E | East(B) |
| 디버그 오버레이 | F1 | — |

조작법은 화면에 표시하지 않는다 (UI 원칙은 CLAUDE.md). 데모 때는 발표자가 안내한다.

## 3-1. HUD
| 요소 | 내용 |
|---|---|
| 감각 메달리온 (좌상단) | 금빛 해 고리 = 공주(빛), 은빛 달 고리 = 왕자(소리). 옆의 작은 메달리온이 짝. 전환 시 튀어오르며 이름 카드가 잠깐 나온다 |
| 챕터 타이틀 | 시작 시 "제3장 · 황혼 · 어둠 속의 왕자, 빛 속의 공주" |
| 의성어 자막 (하단) | 철컥— / 덜컹— / 끼긱— / 쿠르르릉— / …… (공주가 소리를 내려 할 때) |
| 속삭임 (하단) | 디렉터 힌트를 황혼의 목소리로: "…왕자라면, 들을 수 있을지도." |
| 보조 칩 (우상단) | 디렉터가 바꾼 것: ♪ 소리를 더 크게 / ☀ 빛을 더 밝게 / ◆ 금빛을 더 길게 |
| 클리어 | 따뜻한 화면 + "황혼에서 만나다" + ★시간 ◆전환 ♥낙하 |
| 개발 오버레이 | F1, 기본 꺼짐 |

## 4. 캐릭터
- 두 사람은 항상 함께. 조작 중인 쪽이 리더, 다른 쪽은 리더의 0.3초 전 궤적을 따라간다(자율 반응 없음 — 기획서 "의도적으로 빠진 것"과 일치).
- 전환은 위치가 아닌 **감각 렌즈**: 조작 권한과 렌더 모드가 함께 바뀐다.
- 반향은 왕자 전용. 공주 모드에서 R은 "들리지 않음" 피드백(화면 진동선만).

## 5. 비주얼 (임시 아님)
- **공통 지오메트리, 렌더 패스만 다름**: 모든 월드 스프라이트가 `DuskTwilight/SenseSprite` 하나를 쓴다. 전역 셰이더 변수로 모드를 결정.
- **전환 연출**: 조작 캐릭터 위치에서 원형 파면이 0.65초 동안 화면을 덮으며 세계가 뒤집힌다. 파면 테두리는 흰-금 빛.
- **공주 모드(빛)**: 황혼 금색 그레이딩, 위쪽 림 라이트, 하단 장밋빛 그림자, 해·구름·안개가 흐르는 하늘(`DuskTwilight/Sky`). 소리는 `DuskTwilight/SoundGlyph` 진동선으로 보인다.
- **왕자 모드(어둠)**: 남색-검정. 텍스처의 어두운 외곽선을 흰 선으로 반전해 "윤곽만" 남기고, 반향 파면이 지나간 곳만 잠깐 드러난다. 소리 나는 장치는 주기적으로 스스로 파동을 낸다.
- **픽셀 일관성**: PPU 18, Pixel Perfect Camera(480×270). 셰이더의 월드 좌표 효과도 1/18 그리드로 양자화.
- 후처리: Bloom + Vignette (URP Volume).

## 6. 오디오
- 왕자 모드: 발소리, 톱니, 물방울, 바람(런타임 생성 브라운 노이즈) — 풍부하게.
- 공주 모드: 기획서대로 **소리 없음**(마스터 볼륨 0으로 페이드). 대신 진동선과 자막.
